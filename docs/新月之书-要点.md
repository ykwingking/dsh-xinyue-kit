- 装了 `freekill-core` 后，引擎改从 `packages/freekill-core/lua/freekill.lua` 加载（`terminology.rst:43-57`）
  → **改公共行为改这个包的 Lua，不必重编 C++**。
- 本机两套核心并存：旧 `lua/{client,server,core}` 与新的 `packages/freekill-core/ltk/{core,server}`，查 API 先分清。

## 4 事件与回调（`rule/03` + `anhe/09`，引擎实测）

- 回调签名统一 **`(self, event, target, player, data)`**（`ltk/core/skill_type/trigger.lua:23-27`）。
  `target` = 该时机的承担者，`player` = 当前被问的人，**触发不会自动限制 `target == player`**。
- 常用承担者：`fk.Damaged`→受伤者（`data.from` 是来源）；`fk.Damage`→来源；`fk.TurnEnd`→回合角色；
  `fk.EnterDying`→濒死者；`fk.Death`→死者。
- 时机从当前行动者起逆时针逐人询问，优先级：武将 1 / 装备 0.1 / 规则 0（`trigger.lua:10`）。
- 频率在**骨架 tags**（`Skill.Compulsory/Limited/Wake/Switch/Permanent`…，`ltk/core/skill.lua:29-48`），
  spec 里写 `frequency` 引擎不读（`skill_skeleton.lua:295`）。限次用 `max_phase/turn/round/game_use_time`、
  `max_branches_use_time`；效果级再给 `{ check_effect_limit = true }` / `{ check_skill_limit = true }`。

## 11 规则篇补充（`rule/` 全 12 篇读后 + 引擎核对）

### 11.1 事件与技能骨架（`rule/02,03`）

- 技能 = 本体（持有/标签/次数）+ 效果（**首个效果即主效果**）；一次事件 = 前置判断 → 主效果 → 清理效果 → 后续效果，
  插结形成事件栈，**后进先结**（`03:9-56`）。
- 只有正跑主效果的事件可终止；终止 = 停效果 → 跑清理 → **不跑后续效果**（`03:65-69`）。
- 触发流程：从当前行动者起逆时针逐人 → 列出该玩家所有满足条件的触发技 → 多个则问选一个 → 执行消耗
  （`03:91-95`）；**有些时机没有承担者**（移牌、洗牌），此时 `target` 为 nil。
- 回合档次数是**唯一在 `TurnEnd` 之前重置**的（`02:58-79`）：在 `fk.TurnEnd` 里读回合内计数要留意。
- 查询次数用现成 API：`player:usedSkillTimes` / `usedEffectTimes` / `skel:withinTimesLimit(player, scope)`（`02:106-124`）。
- 分支限次：`max_branches_use_time = { 分支名 = { [Player.HistoryTurn] = 1 } }` +
  `skel:withinBranchTimesLimit(player, "分支", scope)`（`02:164-192`）。
- `addEffect` 第三参：`{ check_effect_limit = true }` 只校验本效果、`{ check_skill_limit = true }` 校验整技能、
  `{ is_delay_effect = true }` 不为主技能计次且**默认自动发动**（`02:129-155`）。

### 11.2 移牌（`rule/04` + 引擎实测）

- `data` 是数组 `MoveCardsData[]`；每个元素是一组「同时移动」，元素内 `moveInfo[]` 每张牌一条
  `{cardId, fromArea, beforeCard, fromSpecialName?}`；事件 `target = nil`。
- `from` = 牌主，**牌在牌堆/弃牌堆/处理区/游戏外时为 nil**；`to` 只有 `toArea` 是玩家区域时才非 nil，
  置入 `Card.Void` 必须 `to = nil`（`ltk/server/events/movecard.lua:495-505`）。
- 目标区域已废除（装备栏无槽 / 判定区封印 / 手牌区封印）会被**改写为弃牌堆**，并追加一条
  `moveReason = ReasonPutIntoDiscardPile` 的数据（`04:50`）。
- `Card.Processing` 是「同时移动」的中转：交换手牌 = 先双方同时移入处理区，再同时移入对方手牌（`04:31-36`）。
- 取消移牌只能用 `room:cancelMove(data, ids, func)`，且**只在 `BeforeCardsMove`**；在 `BeforeCardsMove` 里
  `on_use` 返回 true = **终止整个移牌事件**（`AfterCardsMove` 都不发）（`movecard.lua:1035-1054`、`:58-59`）。
- `moveReason` 必填（`ltk/server/system_enum.lua:72-84`：1 JustMove / 2 Draw / 3 Discard / 4 Give / 5 Put /
  6 PutIntoDiscardPile / 7 Prey / 8 Exchange / 9 Use / 10 Response / 11 Judge / 12 Recast / 13 Pindian）；
  `toArea = PlayerSpecial` 时必须给 `specialName`，否则 assert。
- 摸牌专用前置：`fk.BeforeDrawCard{DrawData: who, num, fromPlace = "top"|"bottom"}`（`04:65-78`）。

### 11.3 流程（`rule/05`）

- 开局：`GamePrepared`（无承担者无 data）→ 座位 → 身份 → 选将 → 明将 → 一号位 → 牌堆 → 授技 → `GameStart` →
  `RoundStart` → 回合循环 → `RoundEnd` → `AfterRoundEnd`；第 9999 轮平局；`GameFinished` 的 data = winner（空串 = 平局）。
- 回合：`PreTurnStart` → `BeforeTurnStart`（**返回 true 跳过整个回合**）→ `TurnStart` → 六阶段 → `TurnEnd` →
  `EventTurnChanging{from, to, skipRoundPlus}`。
- 阶段：`EventPhaseChanging`（data.skipped = true 可跳过）→ 跳过则 `EventPhaseSkipping` / `EventPhaseSkipped`；
  未跳过则 `EventPhaseStart`（**返回 true 终止本阶段**）→ `EventPhaseProceeding` → 结算 → `EventPhaseEnd`。
- 阶段内容：判定区牌**后进先判**；摸牌 `DrawNCards` → 摸 2 张 → `AfterDrawNCards`；弃牌弃到上限。
- 初始手牌 `DrawInitialCards` / `AfterDrawInitialCards` **不触发任何移牌时机**。

### 11.4 用牌 / 响应链路（`rule/06`）

`PreCardUse`（返回 true 终止整链）→ 入处理区并计次 → `AfterCardUseDeclared` → `AfterCardTargetDeclared` →
`CardUsing` → `TargetSpecifying`（使用者承担）→ `TargetConfirming`（目标承担）→ `TargetSpecified`（使用者）→
`TargetConfirmed`（目标）→ `BeforeCardUseEffect` → 按牌型结算 → `CardUseFinished` → 处理区剩牌入弃牌堆。

卡牌生效：`CardEffectCancelledOut` → `PreCardEffect`（**打闪/无懈就是这里**）→ `BeforeCardEffect` →
`CardEffecting` → 牌绑定技能生效 → `CardEffectFinished`；途中被抵消或目标已死 → 事件直接结束。
打出：`PreCardRespond` → 入处理区 → `CardResponding` → `CardRespondFinished` → 入弃牌堆。

### 11.5 体力 / 伤害 / 死亡（`rule/07,08`）

- 体力：`BeforeHpChanged` →（伤害时记 `chain_table` 供铁索传导、算 `shield_lost`）→ 再触发一次 `BeforeHpChanged`
  → 变化量与护甲扣减**都为 0 即视为被防止** → 扣护甲 → 改体力 → `HpChanged` → 体力 < 1 濒死。
  （`07:18` 把「体力值变化时」也标成 `BeforeHpChanged`，引擎**没有**第二个独立事件，别为它单独监听。）
- 上限：`BeforeMaxHpChanged` → **变 0 杀死角色** → 体力 > 上限则削到上限 → `MaxHpChanged`。
- 伤害：`PreDamage`(来源) → `DamageCaused` / `DetermineDamageCaused`(来源) → `DamageInflicted` /
  `DetermineDamageInflicted`(受伤者) → `Damage`(来源) / `Damaged`(受伤者) → `DamageFinished`。
  **反直觉：数值未定用非 Determine，数值已定用 Determine；「防止伤害」= 把伤害固定为 0，必须写在 `Determine*` 里。**
- 濒死：`EnterDying` → 逐存活角色 `AskForPeaches`（濒死者还能用酒）→ `AskForPeachesDone` → 体力仍 ≤0 才死 → `AfterDying`。
- 死亡：`BeforeGameOverJudge` → 置已死 → `GameOverJudge` → `Death` → `BuryVictim` → `Deathed`；复活走 `AfterPlayerRevived`。

### 11.6 判定 / 拼点 / 属性（`rule/09,10`）

- 判定：`StartJudge` → 定判定牌 → 对判定牌应用锁视技 → 移入处理区 → `AskForRetrial`（改判技能挂这里）→
  `FinishRetrial` → 揭晓 → `FinishJudge`（返回 true 终止）→ 判定牌入弃牌堆。
