# 安装说明 — dsh-xinyue-kit 1.13.0（离线压缩包）

新月杀(FreeKill)扩展开发工坊，一个 DeepSeek Harness 插件。本文件对应 `dsh-xinyue-kit-1.13.0.zip`。

---

## 一、包里有什么

```
dsh-xinyue-kit/
├── index.js              服务端入口：10 个 xinyue_* 工具 + 规范注入 + skill 自动安装
├── client.js             工坊面板（任务表单 / 历史 / 设置向导）
├── src/                  写入通道、校验器、引擎索引、参考资料、素材匹配…
├── presets/              「新月杀开发模式」人格预设
├── scripts/              维护脚本与测试（test-*.mjs，可直接 node 跑）
├── knowledge/
│   ├── fkbook/           《新月之书》rST 节选（search_reference 读它）
│   └── skills/freekill-skill-authoring/SKILL.md
│                         写技能的踩坑清单（插件加载时自动装到 <dsh home>/skills）
├── docs/                 新月之书-要点.md、screenshots/、本文件
├── cordis.patch.yml      插件补丁声明
├── README.md / LICENSE
```

**不含**：`node_modules/`（依赖只有 `luaparse`）、`.cache/`（引擎索引，首次用时自动重建）、`backup/`。

---

## 二、环境要求

| 项目 | 要求 |
|---|---|
| DeepSeek Harness | 桌面版 **≥ 1.8.1**；Web 版 `dsh` ≥ 0.1.5（peerDependencies 见 package.json） |
| pnpm | 需要（桌面版运行时里有；没有就 `npm i -g pnpm`） |
| 网络 | **仅首次安装**需要联网一次，用来下载依赖 `luaparse`（约 100 KB）。插件本身不联网。 |

---

## 三、安装 A：解压 + 登记（离线可用，最稳）

1. 把压缩包解压到固定位置，例如
   `D:\dsh-plugins\dsh-xinyue-kit`（解压后该目录里直接就是 `package.json`）。

2. 打开 `%USERPROFILE%\.dsh\profiles\desktop\package.json`（Web 版把 `desktop` 换成 `web`），
   加两处——**两处都要加，少一处就不生效**：

   ```json
   {
     "dependencies": {
       "dsh-xinyue-kit": "file:D:/dsh-plugins/dsh-xinyue-kit"
     },
     "dsh": {
       "profile": {
         "bundles": [
           "…原有内容…",
           "dsh-xinyue-kit"
         ]
       }
     }
   }
   ```

   > `file:` 后面用**正斜杠**。只写进 `dependencies` 不写 `bundles` → 装上了但不会被加载；
   > 只写 `bundles` 不写 `dependencies` → 启动时报找不到插件。

3. 在 profile 目录装依赖：

   ```sh
   pnpm --dir "%USERPROFILE%\.dsh\profiles\desktop" install
   ```

4. **完全退出 DSH**（包括托盘图标），再重新启动。

5. 验证：
   - 输入框左侧出现「🛠 工坊」按钮；
   - 让 AI「列出工坊工具」，应答出 10 个 `xinyue_*` 工具；
   - `%USERPROFILE%\.dsh\skills\freekill-skill-authoring\SKILL.md` 自动出现（插件加载时安装）。

---

## 四、安装 B：命令行（等效；须先退出桌面版）

```sh
"D:\软件\Deepseek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "file:D:/dsh-plugins/dsh-xinyue-kit"
```

- 桌面版**正在运行**时执行会报 `EPERM … package.json.lock`，这是文件锁，先退干净再执行。
- 有网络时也可以直接装版本号或仓库：
  `add dsh-xinyue-kit@1.13.0` ／ `add https://github.com/ykwingking/dsh-xinyue-kit.git`
- 装完同样要重启。

---

## 五、安装 C：桌面版插件面板

左侧「插件」面板 →「添加插件」→ 输入包名（或 `file:` 本地路径，视版本而定）→ 安装 → 重启。
面板不支持本地路径时，用上面的 A 或 B。

---

## 六、升级 / 卸载

**升级**：解压新版覆盖目录 → 重启；或 `plugin add` 新版本号。
**卸载**：
1. 从 `bundles` 数组里删掉 `"dsh-xinyue-kit"`；
2. `pnpm --dir "%USERPROFILE%\.dsh\profiles\desktop" remove dsh-xinyue-kit`；
3. 删掉解压目录，重启。

回滚到旧版本：解压旧 zip 覆盖目录即可（工坊的写入备份在游戏包内的 `backup/`，与插件版本无关）。

---

## 七、安装后要做的两件事

1. 工坊页「⚙ 设置」→ 填新月杀本体目录（**同时含 `packages/` 与 `lua/` 的那一层**，例如
   `D:\新月杀\新月杀\FreeKill-v0.5.25\FreeKill-release`），保存到 `~/.dsh/xinyue-kit.json`。
2. 新建会话时选「新月杀开发模式」人格（0.1.7 起随插件自动就位，无需手动重装 preset）。

---

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 重启后没有「🛠 工坊」 | `bundles` 没加，或没有 `pnpm install`，或没完全退出 DSH |
| 启动日志说插件版本不兼容 | 桌面版版本太旧（需 ≥ 1.8.1），或 `@deepseek-ai/dsh-tools` 不在 peerDependencies 范围 |
| 命令报 `EPERM … package.json.lock` | 桌面版还开着，先退出 |
| `pnpm install` 报找不到 luaparse | 首次安装需要联网；可复制别处的 `node_modules/luaparse` 进来 |
| AI 说没有 xinyue_* 工具 | 插件没被加载（看 bundles）或会话是在装插件之前开的——**新开一个会话** |
| skill 没出现或还是旧的 | 插件每次加载会覆盖安装；若项目里存在 `<工作区>/.dsh/skills/freekill-skill-authoring`，它会遮挡用户级那份（rank 100 > 400），删掉项目级副本 |
| 工坊页提示没配游戏目录 | 这是正常的初始化向导，填目录或选「手动复制」写入方式 |
