# 变更说明 — 1.13.0

## 本轮（1.13.0）

- **打包形态改为离线 zip**：`dsh-xinyue-kit-1.13.0.zip`，解压即用，附 `docs/安装说明.md`。
  相比目录直挂多做了三件事：版本号对齐、文档收编、去掉 `node_modules` / `.cache` / `backup`。
- **经验文档收编**：`docs/新月之书-要点.md`（12 节，含「文档勘误表」）随包分发，
  和 `knowledge/skills/freekill-skill-authoring/SKILL.md`（写技能的踩坑清单）互补：
  前者是书的内容摘要，后者是「怎么写才不返工」的操作清单。

## 1.12.x 累积（本轮之前、包含在本包里）

### 1.12.0 — skill 随插件自动安装
- 新增 `src/skill-scaffold.js`：插件加载时把 `knowledge/skills/freekill-skill-authoring/SKILL.md`
  按内容差异覆盖安装到 `<dsh home>/skills/freekill-skill-authoring/SKILL.md`
  （`installed / updated / unchanged / error` 四种结果都会打日志）。
- `KNOWLEDGE_TEXT` 顶部加了指针：动技能代码前先加载该 skill。
- `xinyue_write_package` 成功返回的尾部加一行提醒：本轮新核实的引擎事实要回写 skill。

### 1.12.1 — 图片/音频约定校正
- 纠正长期错误说法「官方语音不拆序号」：官方是**一句一个文件** `<技能ID><序号>.mp3`
  （`packages/standard/audio/skill` 122/122、`packages/mrfz/audio/skill` 12/12 都带序号），
  `Fk/Base/SkinBank.qml:233-246 getAudio` 先试 `<名>.mp3` 再试 `<名>1.mp3`；
  `audio_index` 的 0=不播、不写=随机（`ltk/core/skill.lua:21`）。

### 1.12.2 — 《新月之书》吸收
- 新增/改写 SKILL.md §4.6（语音命名、`audio_index`、Exppattern 七项定序与 `^(3,5)` 取反坑、
  状态技键名只认 `maxcards`/`cardskill`）、§4.7（移牌 `from`/`to` 何时为 nil、`moveReason` 必填、
  `cancelMove` 只在 `BeforeCardsMove`、防伤只能写在 `DetermineDamageCaused/Inflicted`、
  `BeforeTurnStart` 返 true 跳整回合、回合档次数在 `TurnEnd` 前重置、`is_delay_effect` 默认自动发动）、
  §4.8（主动技的 `max_card_num/card_filter` 会在客户端被调用；写了 `can_trigger` 就等于接管默认检查，
  必须自己写 `player:hasSkill(...)`）。
- §7 增补若干条 assert 级坑（移牌漏 `moveReason`/`specialName`、`fk.createSkill` 小写不存在、
  `getMark` 缺省返回 0）。
- 修正文档自身错误清单（回调签名顺序、`metadata.lua` 非必需、`obtainCard` 第 4 参是 reason、
  `total_hidden` 而非 `hidden`、立绘 250×290、`damageType` 而非 `nature` 等）。
